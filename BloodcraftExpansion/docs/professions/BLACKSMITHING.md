# Blacksmithing

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

## Earning experience

Blacksmithing experience comes from weapon-related crafting and recognized weapon items.

## Benefit

Upstream documents crafted gear base-stat improvement up to 10% and durability up to twice baseline at maximum for the relevant equipment category.

## Commands and configuration

- `.prof get Blacksmithing` — inspect progress.
- `.prof log` — toggle profession progress messages.
- `.prof set [Name] Blacksmithing [Level]` — administrator override.
- `ProfessionFactor` — global profession XP multiplier.
- `DisabledProfessions` — include `Blacksmithing` to disable this profession.

## Practical note

Crafted-quality bonuses affect equipment economy; coordinate this with loot and repair settings.
