# Recommended Mods

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

## Upstream recommended

The stable Bloodcraft README recommends these separate projects:

| Mod | Upstream summary |
|---|---|
| KindredCommands | General V Rising server administration tools |
| KindredLogistics | Server-side inventory and logistics improvements |
| KindredArenas | PvP-area control |
| KindredSchematics | Castle copying and creative building tools |
| KindredPortals | Custom portals and waygates |
| KinPoolParty | Listed by upstream among its recommendations |

Eclipse is the dedicated Bloodcraft client companion and is documented separately.

A recommendation is not a compatibility warranty. Check each mod's current release, game version, dependencies, and installation side before use.

## Community recommendations

This project does not currently prescribe an additional server stack. Future suggestions will be labeled community-maintained and tested against named versions.
