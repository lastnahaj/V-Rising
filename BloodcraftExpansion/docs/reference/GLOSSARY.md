# Glossary

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

| Term | Meaning |
|---|---|
| Bloodcraft | The upstream server-side RPG progression mod maintained by mfoltz |
| BloodcraftExpansion | This repository's custom, planned content layer |
| Blood Legacy | Blood-type-specific upstream progression earned through feeding |
| Eclipse | Optional Bloodcraft client UI companion |
| Expertise | Weapon-specific upstream progression |
| Exo Prestige | Endgame prestige path linked to Exo forms and familiar Primal Echoes |
| Familiar | A defeated eligible unit unlocked and summoned through Bloodcraft |
| PrefabGUID | V Rising's numeric identifier for a game prefab; values are game-version-sensitive |
| Prestige | A reset-and-advance progression layer for supported systems |
| Primal Echo | An endgame familiar unlock mechanism tied to Exo progression |
| Shiny | A familiar variant/effect managed with familiar commands and Vampiric Dust |
| Shift slot | The ability slot Bloodcraft uses for class spells |
| Stable | Behavior included in the documented Thunderstore stable release |
| Prerelease | Newer upstream build documented separately and not silently merged into stable behavior |
| V Blood | V Rising boss-class enemy category |
