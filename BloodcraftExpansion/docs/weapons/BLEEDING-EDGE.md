# Bleeding Edge

!!! experimental "Experimental Bloodcraft Feature"
    `BleedingEdge` opts into weapon-specific behavior. Test each selected weapon on a staging server before production use.

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Stable 1.13.22 accepts a comma-separated selection from these five weapon names:

| Weapon | Experimental behavior documented upstream |
|---|---|
| Slashers | Every third chained primary attack applies bleed, stacking up to three times |
| Crossbow | Significantly faster primary projectile |
| TwinBlades | Second weapon skill applies a shield from a frost spell when used on V Blood enemies |
| Pistols | 25% more primary-attack projectile range |
| Daggers | Stacks refresh after the weapon is unequipped |

This option is separate from `PrimalArsenal`, which is also experimental.
