# Endgame Systems

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Bloodcraft’s endgame additions are opt-in and have different maturity levels.

| Feature | 1.13.22 status | Evidence-based summary |
|---|---|---|
| Elite Shard Bearers | Optional / experimental history | Raises shard-bearer challenge when enabled; `ShardBearerLevel` can set a uniform level. |
| Elite Primal Rifts | WIP | Starts Primal War events using `RiftFrequency`; upstream calls the section WIP. |
| Nightmare Mode | Optional, known stable-version issue | PvE-only health, power, and movement tuning. Prerelease 1.13.26 fixes duplicate scaling across restarts. |
| Exo Prestige | Optional | Up to 100 Exo prestiges after normal prestige prerequisites, with configurable rewards. |
| Exo Forms | Experimental | Evolved Vampire and Corrupted Serpent selections are described upstream as potentially unbalanced/janky. |
| Primal Echoes | Optional | Spends Exo rewards to unlock eligible V Blood familiars with tier-scaled cost. |
| Primal Arsenal | Experimental | Replaces supported weapon models/ability loadouts; opt-in. |

Keep these disabled until you have backups and a test environment. Continue to the [Endgame hub](../endgame/README.md).
