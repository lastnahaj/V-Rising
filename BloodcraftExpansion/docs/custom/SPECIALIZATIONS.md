# Specializations

!!! expansion "BloodcraftExpansion Content"
    This page describes custom content designed for this project and is not part of upstream Bloodcraft unless explicitly stated otherwise.

Specializations are planned branches within each custom class. They are intended to sharpen a playstyle without replacing Bloodcraft's upstream class, spell, expertise, legacy, or prestige data.

The current design treats specialization choice as a future implementation phase. Before implementation it needs:

- a durable player-data model;
- explicit unlock and respecialization rules;
- server configuration for costs and limits;
- conflict rules for Bloodcraft class selection and Shift spells;
- Eclipse or chat presentation that never impersonates upstream UI;
- migration and rollback handling.

No specialization branch is enabled by this repository. Detailed class directions are recorded in [Bloodlines & Classes](BLOODLINES-AND-CLASSES.md); implementation gates are tracked in the [Roadmap](ROADMAP.md).
