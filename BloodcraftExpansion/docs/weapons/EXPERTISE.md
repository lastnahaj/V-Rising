# Weapon Expertise Guide

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Using a weapon while defeating enemies advances that weapon's expertise when the system is enabled. Each weapon keeps its own level, chosen statistics, and prestige progress.

Use `.weapon get [WeaponType]` to inspect progress, `.weapon list` for types, and `.weapon liststats` for selectable stats. Selection and reset syntax is recorded in the [command reference](../reference/COMMANDS.md).

Expertise can interact with class weapon-stat synergies, while expertise prestige raises stat caps and changes rate scaling. See [Expertise Stats](../progression/EXPERTISE-STATS.md).
