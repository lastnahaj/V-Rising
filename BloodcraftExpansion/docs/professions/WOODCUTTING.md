# Woodcutting

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

## Earning experience

Woodcutting experience comes from breaking wood resource objects and recognized wood items.

## Benefit

Bonus resources scale with level, with random saplings as the documented profession-specific bonus.

## Commands and configuration

- `.prof get Woodcutting` — inspect progress.
- `.prof log` — toggle profession progress messages.
- `.prof set [Name] Woodcutting [Level]` — administrator override.
- `ProfessionFactor` — global profession XP multiplier.
- `DisabledProfessions` — include `Woodcutting` to disable this profession.

## Practical note

Large yield changes can affect castle progression and economy; tune the global profession factor conservatively.
