# Familiars

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Familiars are persistent enemy unlocks that can be organized, summoned, leveled, equipped, prestiged, and optionally given spell-school “shiny” effects.

## Everyday commands

| Command | Action |
|---|---|
| `.fam l` | List the active box. |
| `.fam b [#]` | Bind an entry from that list. |
| `.fam sb [Name]` | Search and bind by name. |
| `.fam t` | Call or dismiss the familiar. |
| `.fam c` | Toggle familiar combat when allowed. |
| `.fam gl` | Show level, prestige, and currently exposed stats. |
| `.fam ub` | Unbind and destroy the active familiar entity without deleting its unlock. |

Use `.fam actions` to list server-supported emote actions. With emote actions enabled, Beckon enters or exits familiar equipment interaction.
