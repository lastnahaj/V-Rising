# Daily Quests

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Daily quests draw from Bloodcraft's kill, gather, and crafting objective systems. Use `.quest get daily` to view the current assignment and the quest logging/tracking command to control progress messages.

`InfiniteDailies` determines whether players can continue receiving dailies. `DailyPerfectChance` controls the chance for a random perfect gem on completion. Administrators should treat both as balance settings, not fixed rules.
