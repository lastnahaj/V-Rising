# Shift Slot

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

The Shift slot is Bloodcraft's class-spell slot. Players choose an available class spell with `.class choosespell [#]` after meeting its configured prestige requirement. `.class lockshift` toggles whether Bloodcraft manages that slot.

The default shared spell is Veil of Shadow (PrefabGUID `-433204738`). Each upstream class has five configured spell PrefabGUIDs; see the individual [class pages](../classes/README.md).

Eclipse can display and support relevant Shift-slot state, but Bloodcraft remains the authoritative server component.
