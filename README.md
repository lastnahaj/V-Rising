# V Rising

Projects and server tools for V Rising.

## SanguineRelay

[SanguineRelay](SanguineRelay/) connects a V Rising dedicated server to Discord with chat relay, live server information, event notifications, status displays, and administration commands.

- [Documentation](SanguineRelay/README.md)
- [Download v1.0.0](https://github.com/lastnahaj/V-Rising/releases/tag/v1.0.0)
- [Configuration reference](SanguineRelay/docs/CONFIGURATION.md)
- [Discord setup](SanguineRelay/docs/DISCORD-SETUP.md)
- [Troubleshooting](SanguineRelay/docs/TROUBLESHOOTING.md)
