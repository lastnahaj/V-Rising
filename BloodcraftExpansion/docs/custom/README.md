# BloodcraftExpansion

!!! expansion "BloodcraftExpansion Content"
    This section describes custom content designed for this project and is not part of upstream Bloodcraft unless explicitly stated otherwise.

BloodcraftExpansion is a proposed server-content layer built around Bloodcraft's progression foundation. The current repository contains design documentation; a page does not imply that its gameplay exists.

## Current maturity

The roster is at **Concept** status. Architecture, input handling, numeric tuning, persistence, and compatibility must satisfy the [design standards](DESIGN-STANDARDS.md) before any entry is described as implementation-ready.
