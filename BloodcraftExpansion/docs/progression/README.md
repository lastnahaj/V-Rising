# Character Progression

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Bloodcraft layers several independent tracks over V Rising:

1. [Experience Leveling](LEVELING-GUIDE.md) advances the character.
2. [Weapon Expertise](EXPERTISE-STATS.md) advances each weapon type and chosen weapon stats.
3. [Blood Legacies](LEGACY-STATS.md) advance each blood type and chosen blood stats.
4. [Classes](../classes/README.md) multiply configured matching stats and add themed effects/spells.
5. [Prestige](PRESTIGE-TYPES.md) resets completed tracks for repeat progression.
6. [Exo Prestige](EXO-PRESTIGE.md) begins after normal prestige requirements.

Each system can be switched off. Players should check `.lvl get`, `.wep get`, `.bl get`, `.class l`, and `.prestige get [PrestigeType]` to learn what the server actually enabled.
