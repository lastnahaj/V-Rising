# Alchemy

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

## Earning experience

Alchemy experience comes from recognized potions, bottles, flasks, consumables, blood potions/merlots, elixirs, coatings, and related crafting.

## Benefit

Potion effectiveness and duration scale up to twice baseline at maximum. Holy potion effectiveness is excluded, though duration can increase; coating duration is intentionally not extended.

## Commands and configuration

- `.prof get Alchemy` — inspect progress.
- `.prof log` — toggle profession progress messages.
- `.prof set [Name] Alchemy [Level]` — administrator override.
- `ProfessionFactor` — global profession XP multiplier.
- `DisabledProfessions` — include `Alchemy` to disable this profession.

## Practical note

Test combat consumables after rate changes, especially on PvP servers.
