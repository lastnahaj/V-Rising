# Asset Notes

!!! expansion "BloodcraftExpansion Content"
    These original images belong to this repository's custom documentation layer and are not upstream Bloodcraft artwork.

All PNG files in `assets/custom/` are original documentation artwork created specifically for the Bloodlines & Classes design package.

- The visual direction is dark gothic fantasy: blackened stone, blood-red accents, antique gold filigree, moonlit castles, heraldic emblems and class/bloodline portrait cards.
- The package contains a hero banner, Bloodline compendium, Class compendium, identity-stack infographic, and matching individual Bloodline/Class cards.
- The art does not contain extracted V Rising textures, screenshots, logos, character renders, or other copied game assets.
- These images are documentation/concept assets and may be replaced later by final production UI art.

Recommended repository location:
`BloodcraftExpansion/docs/assets/custom/`
