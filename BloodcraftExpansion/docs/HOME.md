# Bloodcraft Wiki

**Master the Blood. Shape the Vampire. Rule Vardoran.**

![Bloodcraft Wiki — custom documentation artwork](assets/custom/bloodlines-classes-hero.png){ .wiki-hero }

*The Gothic artwork on this site was created for BloodcraftExpansion documentation; it is not upstream Bloodcraft artwork.*

This community wiki has two clearly separated areas:

- **Bloodcraft reference** — versioned guides for the upstream server mod maintained at [mfoltz/Bloodcraft](https://github.com/mfoltz/Bloodcraft).
- **BloodcraftExpansion** — custom and planned Bloodlines, Classes, specializations, and future RPG content for this repository.

!!! version "Reference snapshot"
    Official-reference pages target **Bloodcraft 1.13.22 stable** from Thunderstore, source commit `cc34b357e6c3c88e5feadb9b0f7e11ab8d0c904f`, verified 2026-08-23. Newer GitHub prereleases are identified separately.

## Upstream Bloodcraft systems

| System | What it adds |
|---|---|
| [Experience Leveling](systems/LEVELING.md) | Character levels, kill experience, rested XP, sharing, and level scaling. |
| [Weapon Expertise](systems/WEAPON-EXPERTISE.md) | Progress per weapon type, selectable bonus stats, and expertise prestige. |
| [Blood Legacies](systems/BLOOD-LEGACIES.md) | Feeding-based progression for each blood type and selectable blood stats. |
| [Classes](classes/README.md) | Six configurable classes with stat synergies, on-hit themes, and Shift spells. |
| [Familiars](systems/FAMILIARS.md) | Unlockable, summonable, levelable companions with optional prestige and equipment. |
| [Quests](systems/QUESTS.md) | Daily and weekly objectives, rewards, tracking, and rerolling. |
| [Professions](systems/PROFESSIONS.md) | Gathering and crafting progression across eight professions. |
| [Prestige](progression/PRESTIGE-TYPES.md) | Repeat progression for leveling, weapons, blood legacies, and Exo endgame. |
| [Endgame](systems/ENDGAME.md) | Optional elite encounters, Nightmare Mode, Exo forms, and Primal Echoes. |
