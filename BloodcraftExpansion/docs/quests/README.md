# Quests

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Bloodcraft can assign daily and weekly kill, gather, and crafting objectives. Progress, tracking, rewards, and rerolls are exposed through the `.quest` command group.

- [Daily Quests](DAILY-QUESTS.md)
- [Weekly Quests](WEEKLY-QUESTS.md)
- [Rewards](REWARDS.md)
- [Rerolling](REROLLING.md)

All objective pools, reward PrefabGUIDs, quantities, reroll costs, and perfect-gem chances are server-configurable.
