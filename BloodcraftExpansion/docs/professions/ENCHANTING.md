# Enchanting

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

## Earning experience

Enchanting experience comes from recognized gems, jewels, magic sources, and related crafting.

## Benefit

It belongs to the crafted-equipment profession group that can improve relevant base stats up to 10% and durability up to twice baseline at maximum.

## Commands and configuration

- `.prof get Enchanting` — inspect progress.
- `.prof log` — toggle profession progress messages.
- `.prof set [Name] Enchanting [Level]` — administrator override.
- `ProfessionFactor` — global profession XP multiplier.
- `DisabledProfessions` — include `Enchanting` to disable this profession.

## Practical note

`ExtraRecipes` also adds Primal Jewel crafting, but enabling recipes is separate from enabling Enchanting.
