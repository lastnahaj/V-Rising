# Tailoring

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

## Earning experience

Tailoring experience comes from recognized armor, cloaks, bags, cloth, and clothing-piece crafting.

## Benefit

Upstream documents relevant crafted gear base-stat improvement up to 10% and durability up to twice baseline at maximum.

## Commands and configuration

- `.prof get Tailoring` — inspect progress.
- `.prof log` — toggle profession progress messages.
- `.prof set [Name] Tailoring [Level]` — administrator override.
- `ProfessionFactor` — global profession XP multiplier.
- `DisabledProfessions` — include `Tailoring` to disable this profession.

## Practical note

Current changelog notes that bag inventory slots are not increased by Tailoring; do not promise extra slots.
