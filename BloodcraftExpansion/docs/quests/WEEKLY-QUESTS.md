# Weekly Quests

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

Weekly quests use the same kill, gather, and crafting framework as daily quests but use weekly progress and reward cadence. Use `.quest get weekly` to inspect the current assignment.

The stable upstream description applies a ×5 multiplier to configured reward quantities for weeklies. A completed weekly cannot be rerolled.
