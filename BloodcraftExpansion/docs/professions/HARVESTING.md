# Harvesting

!!! version "Upstream Bloodcraft Reference"
    **Bloodcraft version:** 1.13.22 stable<br>
    **Last verified:** 2026-08-23<br>
    This page documents upstream Bloodcraft, not BloodcraftExpansion custom features.

## Earning experience

Harvesting experience comes from gathering vegetation and recognized plant or trippy-shroom items.

## Benefit

Bonus gathered resources scale with level, with random seeds as the documented profession-specific bonus.

## Commands and configuration

- `.prof get Harvesting` — inspect progress.
- `.prof log` — toggle profession progress messages.
- `.prof set [Name] Harvesting [Level]` — administrator override.
- `ProfessionFactor` — global profession XP multiplier.
- `DisabledProfessions` — include `Harvesting` to disable this profession.

## Practical note

Review the effect on seed scarcity before using a high `ProfessionFactor`.
